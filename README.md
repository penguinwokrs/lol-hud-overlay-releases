# LoL HUD Overlay（配布用）

League of Legends の観戦（リプレイ含む）画面に、放送風の HUD を重ねる Windows アプリの配布場所です。ソースコードはここにはありません。

> **アルファ版**です。機能や見た目は今後変わります。各版の内容は [Releases](https://github.com/penguinwokrs/lol-hud-overlay-releases/releases) のノートを見てください。

## インストール

1. [Releases](https://github.com/penguinwokrs/lol-hud-overlay-releases/releases/latest) から `LoL-HUD-Overlay_*_x64-setup.exe` をダウンロードして実行する
   - コード署名がないため「Windows によって PC が保護されました」と出ることがあります。「詳細情報」→「実行」で進めてください
   - ユーザーごとのインストールです（管理者権限は不要）
2. 起動するとタスクトレイにアイコンが出ます。表示の切り替え・設定・終了はそこから

## 更新

起動時と 6 時間ごとに新しい版を確認し、観戦中でなければ自動で入れます（入れるときにアプリは一度終了します）。

## 使い方

- 観戦画面は**ボーダーレスウィンドウ**にしてください
- ショートカット（既定。ゲームが前面のとき）: Shift+H 表示 / 非表示、Shift+R 読み直し、Shift+O 設定画面（ショートカットは設定画面で変えられます）
- 自分がプレイしているときは何も表示しません（観戦専用）
